# Career Connect

A full-stack MERN job portal application where users can browse, add, edit, and manage job postings.

## Tech Stack

- React
- React Router
- Tailwind CSS
- Node.js (Coming Soon)
- Express.js (Coming Soon)
- MongoDB (Coming Soon)

## Features

- Browse Jobs
- View Job Details
- Add Job
- Edit Job
- Delete Job
- Responsive UI
